# 界面规则（044 v3 起生效）

改界面前先读这页。审查也照这页查；和这页冲突的样式改动，先改这页再改代码。
对比度、字号下限、荧光按钮这些视觉底线在 [style-guide.html](./style-guide.html)（026）和
[`docs/specs/026-visual-hierarchy.md`](../specs/026-visual-hierarchy.md)。这页只管结构。

可点原型：[`prototype-044/v3-layered.dc.html`](./prototype-044/v3-layered.dc.html)（044 定稿，用户 2026-11-04 认可）。
原型和这页冲突时，以原型的观感为准，回来改这页。

## 三条总规矩

### 1. 一层只开一层

第一层给一句话和几行，点开才是细节。

- **工作台**第一层：一句现状 + 四行（等你拍板 / 在跑 / 排队 / 今天完成，各一个数字和一句预览）。
- 点一行 → 进那一组的列表（顶上是「工作台 › 等你拍板」，点「工作台」回去）。
- 点任务 → 右侧滑出详情；详情里的过程 / 结果 / 审计先折着。
- 数据格、小图、额度**不摆在工作台**，它们在剧组和记录。

不跳层，也不一页摆全（v2 就是摊在一页被推翻的）：一屏只回答一个问题。能就地展开的（额度小卡、剧组一人一行）不要跳页；只有「进一个集合」才换层。

### 2. 墨色 + 一个黄绿色相，只靠饱和度分轻重

- 全站只有一支彩色：`--accent` 黄绿。要彩色字用 `--accent-ink`（荧光黄绿不能当字色），不新开色相。
- 轻重只靠饱和度：**要你管的最饱和**，在跑的淡黄绿，排队 / 完成是灰。
- 不再用橙、红、蓝、绿区分状态；执行者头像统一墨色（`avatar()` 不接颜色）。
- 颜色只取 `public/style.css` 里 `:root` 的变量，不写死；深浅两套主题都要看过。

### 3. 符号能代替的字就不写

| 符号 | 意思 |
|---|---|
| `▶ 3` | 在跑 3 个 |
| `‖ 2` | 排队 2 个 |
| `! 1` | 有 1 件等你 |
| `✕ 2` | 2 件没成 |
| `›` | 进下一层 / 还能展开 |
| `×` | 关闭 |
| `✓` | 刚做完（按钮点完的即时回应） |

- 符号只替「数量 + 一种状态」这种短语；一整句话该写还是写。
- 每个符号都要有 `aria-label` 或 `title`，读屏和鼠标悬停都能得到同样的意思。
- 符号不自己发明：要加一个，先加进这张表。

## 三层组件

**原子**只做一件事；**分子**是一个对象，全站只有一个实现；**组织**是一页。

| 原子 | 细进度条 | `progressBar()` | `components.ts` |

| 原子 | 一个小圆点 | `dot()` | `components.ts` |

## 一个对象一种长相

同一个任务在工作台、剧组、看板长得一样，因为它们调的是同一个 `taskCard()`。
同一个执行者头、同一张审批卡同理。**改一个对象只改一个函数。**

## 一个对象一个地址

- 点任务卡 → `/tasks?task=<id>`，不管这张卡出现在哪一页。
- 点执行者那一行 → 就地展开／收起；展开后的「改设置」打开 `/team?exec=<key>`。
- 详情一律在抽屉里，不做整页详情。

地址就是状态：刷新、收藏、贴进推送都要落到同一个地方。

## 卡片默认只露四样

标题、谁干的（头像 + 名字）、阶段点、一句现状；最多再给一个动作按钮。

动作按状态三选一：排队中给「开始」，等你审批给「去审批」，失败给「重试」；都不适用就不放按钮。

## 不摆空表单

新建、编辑一律在抽屉里。抽屉第一屏最多 3 个必填项，其余收进「更多选项」。

页面上出现 `input`、`textarea`、`select` 只有一个理由：那块本身就是「正在做的事」（比如顶部派活、备忘记一条）。
管理块里只显示数值，改数值走「改设置」。

## 数字带口径

`12` 不叫数字，`近 30 天 12 单` 才是。写清是「今日」「近 30 天」「当前窗口」还是「这次运行」。
样本少于 5 的时候不给百分比，只给条数。

## 动效：写体感，不写毫秒

要的感觉：**轻、快、有因果**。点了一行，下一层马上就出来；新东西是「出现的」，不是「弹出来的」。

不要的感觉：弹跳、缩放、转圈、慢慢淡、一次动好几个地方；不要为了让人看见而让页面在动。

- 换层：淡着上来一点点，别整页平移。
- 滑出详情：从右侧推过来，关掉原路退回；遮罩只是压暗，不闪。
- 列表刷新：只有新出现的卡淡入；状态变了的换一次色就停，不叠加第二套。
- 展开：是「变高」，不是「翻牌」；收起不带动画抢注意力。
- **唯一的硬规则**：系统开了「减少动态效果」，所有动画都停（`@media (prefers-reduced-motion: reduce)`）。
- 038 的「0.2 秒上限」作废：不写毫秒数，也不写曲线。

## 常见走错

- 工作台又摆回数据格、小图、额度 —— 见 1，这些在剧组和记录。
- 给状态加一个新颜色 —— 见 2，用饱和度分级。
- 把「等你拍板」写成一句话再配三个按钮 —— 见 3 和「卡片只露四样」。
- 三个页面各抄一份任务卡，改一处忘两处 —— 见「一个对象一种长相」。
- 给管理块加输入框「省一次点击」 —— 见「不摆空表单」，点一下抽屉更省。
- 为了「信息全」把审计、日志、对比摊在卡片正面 —— 点开再看。
