DESIGN · STYLE GUIDE

一个色系，重要的事一眼能看到

暖灰纸底 + 墨色 + 荧光黄绿。其他颜色只表示状态，不拿来装饰。

色板

纸底--bg #F4F4F0
卡片--panel #FFFFFF
墨色--ink #18181B
荧光黄绿（只做填充）--accent #D7F25A
荧光底--accent-soft #EEF8C4
深橄榄（彩色字用这支）--accent-ink #3B5200
注意--warn #9A3412
危险--danger #B91C1C
成功--ok #166534
进行中--info #1D4ED8

荧光黄绿在白底上的对比度只有 1.25:1，永远不要拿它当文字色；要彩色的字就用 --accent-ink（白底 8.8:1）。
